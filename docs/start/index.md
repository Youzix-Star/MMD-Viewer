# 快速开始

**MMD Viewer** 是一款 Web 端 MMD/PMX 模型查看器：

- **4 个内置模型**：Kasane Teto SynthV（×2）、Sour 式初音ミク（White / Black）
- **实时物理模拟**：裙摆、头发、领带自然摆动，支持风力与微调
- **VMD 动作播放**：内置舞蹈 + 导入自定义动作 / 镜头 / 音乐
- **Material Design 浅色主题**，手机浏览器直接打开
